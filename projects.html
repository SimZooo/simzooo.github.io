snare

(github)

Lightweight web security auditing tool that acts as a man‑in‑the‑middle intercepting proxy for HTTP and HTTPS traffic. It accepts traffic from a configured browser, parses and logs requests, and provides an interface for interactively modifying messages before forwarding them to the target server. It also includes built‑in request replaying, JWT token decoding/encoding, directory fuzzing and a bruteforcing tool.
